# 📊 Customer Churn Prediction

A machine learning web application that predicts whether a telecom customer is likely to churn.

## 🚀 Features

- Customer churn prediction
- Churn probability
- Stay probability
- Risk-level classification
- Retention recommendation
- Model feature importance visualization
- Interactive Streamlit interface
- Random Forest machine learning model

## 🧠 Machine Learning

The project uses a Random Forest Classifier trained on the Telco Customer Churn dataset.

### Dataset

The dataset contains customer information such as:

- Gender
- Senior Citizen status
- Partner and Dependents
- Tenure
- Phone and Internet services
- Online Security
- Online Backup
- Device Protection
- Tech Support
- Streaming services
- Contract
- Payment Method
- Monthly Charges
- Total Charges

## 📈 Model Performance

- Algorithm: Random Forest Classifier
- Accuracy: 78.54%
- Training samples: 5,625
- Testing samples: 1,407
